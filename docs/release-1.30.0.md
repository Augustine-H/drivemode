# 보이스 그록 1.30.0

음악·보컬 생성에서 기존 무료 로컬 모델과 ElevenLabs Music v2.5 유료 API를 선택할 수 있다. 기본값은 로컬이며 채팅·음성 명령은 계속 로컬 모델로 생성한다.

## 변경 사항

- 설정 → 음악 생성 · NAS 연결에 생성 모델 선택과 연주곡 생성 화면을 추가했다. 설정에서 연주곡·보컬곡은 10~120초, 유료 보컬 가사는 4,000자까지 입력한다.
- 유료 생성 전 곡 설명·가사 전송과 비용에 명시적으로 동의해야 한다. 공급자·설명·가사·길이 변경 시 동의가 초기화된다. Worker의 키 등록 여부와 실제 Music API 이용 권한은 구분한다.
- Windows Worker에서 ElevenLabs를 호출하고 WAV·MP3를 NAS에 보관한다. API 키는 기존 Windows DPAPI 또는 Worker 환경변수에서 읽는다. NAS·브라우저·소스코드에 키를 전달하지 않는다.
- 작업별 호출 기록으로 중복 호출을 차단한다. 실패·타임아웃 시 자동 재시도나 다른 유료 공급자로 전환하지 않는다. 전송 후 취소해도 공급자의 생성·과금이 취소된다는 보장은 없다.
- 생성 카드에 공급자·모델·예상 비용과 WAV의 출처를 표시한다. 미디어 라이브러리에도 공급자·모델을 기록한다.
- 변경 없는 미디어 갱신이 재생 위치를 초기화하던 문제를 수정했다. 실제 파일 변경·삭제·휴지통·누락은 계속 반영한다.

## 검증

Python 84개, TypeScript 13개 테스트, 타입 검사와 프로덕션 빌드가 통과했다. 개발 화면과 최신 프로덕션 빌드의 데스크톱·모바일 렌더링, 콘솔 오류, 가로 넘침을 확인했다.

실제 Starter 계정에서 연주곡과 직접 작성한 한국어 가사 보컬곡을 각각 한 번 생성했다. 모두 HTTP 200으로 성공했고 NAS 저장·다운로드 해시 일치와 WAV·MP3 전체 프레임 디코딩을 확인했다. 두 음원 모두 브라우저에서 끝까지 재생했다.

| 검증 음원 | 실제 길이 | API 생성 및 WAV 디코딩 |
| --- | ---: | ---: |
| 연주곡 | 30.040816초 | 9.079초 |
| 한국어 보컬 | 30.040816초 | 4.484초 |

시간에는 NAS 큐 대기·업로드·브라우저 폴링이 포함되지 않는다. 두 파일은 44.1 kHz 스테레오이며 WAV는 PCM 24-bit, 재생용 MP3는 320 kbps다. 연주곡 재생 중 상태 갱신에서도 음원 소스와 재생 진행이 유지됐다.

## 사용 조건과 검증 범위

- Music API는 이용 가능한 유료 플랜과 등록된 키가 필요하다. 최초 Free 계정 호출은 HTTP 402로 거절됐다.
- 표시 단가 기준 30초 $0.075, 두 성공 요청의 합계 예상 $0.15다. 실제 청구액·세금·계정별 과금은 확인하지 않았다.
- WAV는 공급자 MP3를 디코딩한 파일이다. WAV 저장이나 320 kbps 재인코딩은 공급자 원본의 음질을 높이지 않는다.
- 가창 목소리는 고정하지 않으며 페르소나 대화 목소리와 연결되지 않는다. 곡별로 보컬 음색이 달라질 수 있다.
- 한국어 가사 내용은 별도 로컬 Qwen 받아쓰기로 확인했다. CER 7.46%에는 받아쓰기 오인식도 포함되므로 생성 보컬의 발음·청감 품질 점수가 아니다.
- 60초·120초 유료 생성과 영어·일본어 보컬 품질 비교는 아직 검증하지 않았다.
