# 보이스 그록 1.34.8

ElevenLabs 120초 음악 생성에서 정상 응답이 길이 검증 실패로 처리되던 문제를 수정했다. 보존한 실제 MP3는 libsndfile에서 120.311542초, 실제 WAV 변환에 사용하는 FFmpeg에서 120.032653초로 디코딩됐다. 이제 FFmpeg로 변환한 PCM WAV의 전체 프레임과 길이를 검사해 저장할 음원과 검증 기준을 일치시킨다. ±0.25초 허용 범위는 유지한다.

완전히 수신한 공급자 MP3는 검증 전에 보존하며 SHA-256·바이트 수·실제 디코딩 정보와 요청 길이 오차를 기록한다. 잘못된 완전 응답은 진단용으로 남기고 불완전한 네트워크 전송은 삭제한다. 기존 무료 모델 기본값, 유료 호출 동의, DPAPI 키 보관, 실패 작업 중복 호출 차단은 유지한다.

## 검증과 비용

- Python 86개 테스트 통과. 실패 응답 보존, 길이 오차 기록, 동일 작업 재호출 차단, 완전 응답·부분 전송 처리를 검사했다.
- 타입 검사와 프로덕션 빌드 통과. 개발·운영 빌드의 PC·모바일 화면을 시각 검사했고 콘솔 오류·가로 넘침이 없으며 개발/운영 baseline이 일치했다. Windows 검증에서는 설치된 Chrome을 사용했다. 최초 빌드의 로컬 npm 경로 오류는 검증용 실행 wrapper를 바로잡아 재실행했고 최종 빌드는 정상 종료했다. 기존 플랫폼 공유 카드 안내와 번들 경고는 이번 수정과 무관하게 남아 있다.
- 실제 120초 요청 1회 후 보존 응답을 추가 API 호출 없이 수정된 처리기로 검증했다. WAV·MP3 모두 120.032653초이며 비무음·유한 값·44.1 kHz 스테레오·전체 디코딩 검사 통과.
- Windows Worker에 수정 코드 반영 및 재시작 완료. 새 세션의 작업 수락과 브리지 연결을 확인했다. 원래 실패 작업 상태는 변경하지 않았다.
- 최초 후속 테스트는 60초 연주곡 및 영어·일본어 30초 보컬 성공, 120초 길이 검증 실패였다. 가사 CER은 영어 1.62%, 일본어 12.70%(읽기 기준 9.76%), 기존 한국어 7.46%다. 서로 다른 가사·각 1회 표본이며 받아쓰기 오류가 포함되므로 청감 품질 순위가 아니다.
- 표시 단가 기준 최초 후속 테스트 $0.60와 진단용 120초 요청 $0.30, 합계 예상 $0.90. 실제 청구액은 미확인이다. 진단 이후 추가 유료 호출은 없었다.

이번 변경은 Worker와 출시 소스의 패치다. NAS API 변경은 필요하지 않다. Worker 검증 이후 NAS·Grok 웹앱도 아래와 같이 별도로 재게시했다. 자동 재시도나 음원의 강제 자르기·늘리기는 적용하지 않았다.
