무료 로컬 ACE-Step(기존 고정 모델·8단계)로 11개 원곡 후보를 생성했다. 영어·일본어 60초의 가사를 16행에서 8행으로 줄이고, 일본어 네 절을 각각 30초로 생성해 비교했다. 일본어 60초에는 같은 가사를 같은 시드로 유지하며 설명에 가사 그대로·순서 유지 지시를 추가했고 두 시드를 비교했다. 120초는 기존 32행에서 16행으로 줄인 후보를 추가했다. 신규 유료 호출은 0이며 정답 가사는 ASR에 제공하지 않았다.

표는 요청 가사와 로컬 Qwen 받아쓰기의 편집 거리 불일치율이다. 실제 가창 오류율·청취 품질 점수가 아니며 표기 차이·ASR 및 구간 병합 오류도 포함한다. 서로 다른 가사 분량의 수치를 통제된 개선율로 계산하지 않는다.

## 판단

- 영어 8행 후보는 Qwen에 요청한 모든 구절이 나타나지만 마지막 창에서 추가 문장을 인식한다. 독립 Whisper는 마지막 추가 문장을 인식하지 않고 `Feels like coming home again`을 다른 문구로 인식한다. 완벽한 가사 준수로 승인하지 않는다.
- 일본어 시드 61903의 8행 동일 조건에서는 순서 유지 지시를 추가해 17.81%에서 5.48%로 줄었지만, 시드 61904에서는 21.92%에서 19.18%로 작은 차이였다. 시드·ASR에 의존하므로 기본 생성 설명을 강제로 변경하지 않는다.
- 독립 Whisper에서도 일본어 두 지시 후보에 가사 전반이 나타나나 Qwen과 문구가 다르게 인식된다. 원어민 발음 승인과 같지 않다.
- 일본어 30초 4행 분할 후보는 23.53–44.74%로 개선되지 않아 자동 분할·합성을 채택하지 않는다.
- 일본어 120초 16행+순서 지시 후보는 18.06%지만 원본과 가사 분량·설명 두 변수가 달라 각각의 효과를 분리하지 않는다. 반복·마지막 문구 변경이 남았다.

## 적용 범위

웹 1.36.1은 무료 영어·일본어 생성에 가사 행 수와 길이별 시험 시작 분량을 표시한다(60초 8행, 120초 16행). 줄 길이·템포가 달라 이것은 경험적 안내이며 입력 제한·정확도 보장이 아니다. 한국어·유료 공급자에는 이 안내를 적용하지 않는다. 가사·곡 길이를 자동으로 바꾸거나 ASR로 가사를 덮어쓰지 않는다. 모델·CFG 0.9는 유지한다.

원곡의 CUDA 할당 최대는 60초 약 8244MiB, 120초 8782MiB다. RAM은 원곡 생성 프로세스 표본 최대 약 12385–12436MiB다. 장치 전체 메모리는 다른 앱을 포함한다. 원곡 Worker 전체 시간은 큐 대기·NAS 업로드를 포함하지 않는다.
