# 페르소나 가창 사용 안내

보이스 그록 1.36.0에서는 무료 로컬 생성을 기본으로 사용한다. 보컬 원곡은 ACE-Step이 생성하고, 페르소나 목소리 옵션을 켜면 PC에서 보컬 분리·Seed-VC 음색 변환·반주 합성을 이어서 수행한다. 연주곡의 무료 엔진은 Stable Audio다.

## 생성하기

1. 아라 또는 서연 대화 탭을 선택한다.
2. 설정 → 음악 생성 · NAS 연결에서 연결 상태가 정상이고 Windows Worker가 준비됐는지 확인한다.
3. 음악·보컬 생성 모델 선택에서 **로컬 · API 비용 없음**을 선택한다.
4. 보컬 노래 만들기에서 **보컬 언어**를 한국어·영어·일본어 중 선택하고, 직접 쓴 해당 언어 가사, 곡 분위기, 길이(10~120초)를 입력한다. 기본 언어는 한국어다.
5. **페르소나 목소리로 노래**를 켜고 생성한다. 현재 검증된 목소리는 아라·서연이다.
6. 음악 카드가 **음악 완성 · NAS 보관 완료**로 바뀌면 카드 안의 오디오 재생 버튼으로 듣는다.

완성 카드는 MP3 재생·다운로드, WAV 다운로드·앱 저장을 제공한다. 화면 아래의 마지막 페르소나 답변 재생 버튼은 대화 답변을 읽는 기능이므로 음원은 음악 카드에서 재생한다. 생성 중 새로고침했을 때는 기존 작업 상태를 확인하고, 새로운 생성 버튼으로 같은 요청을 다시 제출하지 않는다.

## 비용과 대기 시간

로컬 경로는 API 비용 없이 PC의 GPU·전력·저장공간을 사용한다. PC와 NAS가 연결돼 있어야 하며 여러 요청은 순차 처리한다. ElevenLabs는 선택 가능한 유료 원곡 공급자다. 비용 동의가 있어야 호출되고, 페르소나 변환을 선택해도 추가 변환은 로컬에서 수행한다. 유료 사용을 선택하면 로컬과 다른 비용·이용 조건이 적용된다.

RTX 4070 Ti의 2026-10-10 무료 테스트에서는 60초 곡 생성+변환이 58~74초, 120초는 81~90초였다. NAS 접수부터 보관까지는 각각 70~86초, 98~106초였다. 큐 대기, PC 부하, 곡과 모델 로딩에 따라 달라지는 실측 예시다.

## 품질 확인

페르소나 옵션은 xAI 참조를 기준으로 음색을 변환하는 방식이다. 목소리의 완전한 재현이나 모든 음역·곡에서 같은 품질을 보장하지 않는다. 30초·60초·120초 무료 출력은 사용자 청취에서 긍정적으로 평가됐지만, 가사 전부가 정확히 불렸는지나 후반부의 모든 발음이 검수됐다는 뜻은 아니다.

특히 발음, 두 목소리의 구분, 길게 끄는 음, 후반부 음색을 확인한다. 발음이 뭉개졌을 때는 변환 전 원곡과 비교해 원곡 생성 문제와 변환 문제를 구분한다. 서로 다른 원곡의 음색 비교에는 멜로디·음역 차이가 섞이므로 같은 원곡의 변환본을 비교하는 편이 정확하다. 자동 길이·PCM·파일 검사 통과는 청취 품질 승인과 별개다.

동일 원곡 아라·서연 비교 후 사용자가 선택한 변환 CFG 0.9를 운영 경로에 적용했다. 0.7·0.9·1.0 비교 중의 선호 결과이며 모든 새 곡에서 동일한 개선을 보장하는 판정은 아니다.

이 설정으로 만든 아라·서연 120초 음원은 사용자 청취에서 후반부까지 발음과 음색이 자연스럽게 유지되는 것으로 확인됐다. 두 음색은 자세히 들으면 구분되는 수준으로 평가됐으며, 모든 곡에서 즉각적인 구분을 보장하지 않는다. 현재 한국어 검증곡에 대한 청취 승인이고 외국어·다른 음역·장르에는 별도 평가가 필요하다.

세부 측정과 게시 기록은 [1.35.0 출시 기록](./release-1.35.0.md)을 참고한다.

영어·일본어 페르소나 가창은 [별도 로컬 진단](./multilingual-persona-singing-probe.md)에서 생성·변환을 검증했고 사용자 청취에서 자연스럽다는 평가를 받았다. 1.36.0은 운영 메뉴의 언어 선택을 제공한다. NAS·Worker가 아직 갱신되지 않은 경우 영어·일본어 선택에 ‘서버 업데이트 필요’를 표시하고 생성을 차단한다. 외국어 장시간·다른 장르의 품질은 별도 확인이 필요하다.

1.36.0 운영 영어 아라·일본어 서연 30초 원곡/변환 비교는 사용자에게 “특별한 문제 없이 자연스러움” 청취 평가를 받았다. 후속 영어·일본어 × 아라·서연 × 60·120초 총 8곡도 생성·파일 검증을 통과했다. 후반부 비교 청취에서 영어는 잠정 수용, 일본어는 괜찮게 들리지만 발음 정확도는 판단하기 어렵다는 평가를 받았다. 현재 CFG 0.9를 유지하며, 전체 가사 준수와 일본어 발음 정확도는 추가 검증이 필요하다.
