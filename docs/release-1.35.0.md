# 보이스 그록 1.35.0

보컬 노래 생성에서 아라·서연 페르소나를 선택할 수 있다. 무료 ACE-Step 또는 유료 ElevenLabs 원곡을 생성한 뒤 PC에서 보컬을 분리하고 Seed-VC로 선택한 음색을 변환해 반주와 합친다. 기본 생성 공급자는 계속 무료 로컬이다. ElevenLabs는 비용 동의가 있어야 호출하며 페르소나 참조 음성을 전송하지 않는다.

음색 변환은 기존 Windows GPU 작업 큐에서 순차 실행한다. 필요한 모델·참조 파일이 없는 목소리는 선택을 차단하고 다른 목소리로 대체하지 않는다. 유료 원곡·호출 기록을 보존하며 변환 실패 때문에 유료 생성을 자동 반복하지 않는다. 원곡 생성 후 취소하면 변환을 건너뛴다. 변환 중 취소하면 완료된 음원을 보존한다.

## 검증과 한계

- 사용자 청취에서 ElevenLabs 원곡과 아라·서연 변환본이 같은 평가 구간에 대해 수용됐다. 곡·음역별 동일 품질이나 xAI 음색의 완전한 재현을 보장하는 결과는 아니다.
- 이전에 구매한 30.0408초 원곡으로 새 Worker 큐 경로를 검증했다. 유료 호출 부분만 명시적인 진단 파일 재생으로 대체했고 실제 분리·CUDA 음색 변환·반주 합성·MP3 인코딩을 실행했다. 아라 35.64초, 서연 35.36초; Seed CUDA 할당 메모리 최대 2712.03/2716.53MiB. WAV·MP3 전체 디코딩 및 유한 값 검사 통과. 이 검증의 신규 유료 API 호출·추가 비용은 0이다.
- 유료 요청 동의, API·웹앱 규약, 취소, 변환 실패 시 원곡 보존과 자동 재호출 방지, 누락된 변환 메타데이터로 원곡이 덮어써지지 않는 것을 테스트했다.
- 무료 직접 참조 가창과 공개 DiffSinger 목소리는 청취 품질을 통과하지 못해 운영 기본 경로로 채택하지 않았다. RVC와 관련 진단·학습 도구는 연구용이며 현재 운영 변환은 Seed-VC다. 페르소나별 가창 데이터 학습은 준비된 검수 데이터가 없어 완료되지 않았다.
- 인증 키는 기존 DPAPI 로컬 저장 방식으로 관리한다. GitHub 소스에 음성 참조·학습 자료·모델 가중치·인증 파일을 포함하지 않는다. NAS는 큐와 음원 보관을 담당하며 생성·변환은 Windows Worker가 수행한다.

상세 실험과 준비 조건은 [Persona Singing Voice v1 기록](./persona-singing-voice-v1-local-prototype.md)을 참고한다. 새 버전의 최종 테스트·게시 결과는 아래에 기록한다.

## Grok 무료 가창 실사용 검증 · 2026-10-10

사용자 승인 후 기존 NAS 연결 키를 Grok 브라우저의 암호화 저장소에 등록했다. 임시 연결 파일은 가져오기 직후 제거했고 새로고침 후에도 연결·완성 작업이 유지됐다. 기본 생성 모델은 무료 로컬을 유지했다.

Grok의 실제 생성 메뉴로 동일한 한국어 가사·분위기의 30초 작업을 아라와 서연에 각각 요청했다. 별도 원곡을 생성한 기능 검증이며 동일 원곡을 이용한 두 음색 비교 실험은 아니다.

| 목소리 | Worker 생성·변환·인코딩 | NAS 접수부터 보관 완료 | 로컬 음색 변환 |
| --- | ---: | ---: | ---: |
| 아라 | 70.493초 | 86.128초 | 47.640초 |
| 서연 | 69.196초 | 81.937초 | 47.344초 |

양쪽 WAV·MP3를 NAS에서 다시 받아 크기·SHA-256을 확인했다. 모두 30초·48kHz·2채널이며 전체 디코딩·유한 PCM·피크 검사 통과. Grok 앱 라이브러리에 양쪽 WAV를 저장했고 각 음악 카드의 실제 오디오 재생 시간이 진행되는 것을 확인했다. 추가 유료 호출은 0이다. 이 30초 출력은 이후 사용자 청취에서 “괜찮네”로 수용됐다. 곡·길이가 달라진 출력은 별도 청취 평가가 필요하다.

CUDA 할당 최대는 각 8091.75MiB, 프로세스 RAM 표본 최대는 아라 12364.16MiB·서연 12419.14MiB였다. 음원·검증 보고서는 로컬 `artifacts/grok-free-singing-1.35.0/`, 재생 증거는 `screenshots/grok-free-1350-ara-playing.png`와 `screenshots/grok-free-1350-eve-playing.png`에 보관한다.


## 무료 페르소나 가창 60초·120초 검증 · 2026-10-10

사용자 승인 후 기존 NAS API와 Windows Worker로 무료 ACE-Step 원곡 생성 및 Seed-VC 아라·서연 변환을 순차 실행했다. 60초 양목소리 파일 검증 통과 후 120초를 실행했다. 유료 호출은 0이다. 가사는 직접 작성했으며 120초에는 절을 추가했다. 원곡과 변환본을 모두 보존했다.

| 목소리·길이 | 원곡 로딩 | 원곡 추론 | 원곡 생성+변환 | NAS 접수→보관 | CUDA 할당 최대 | 프로세스 RAM 표본 최대 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 아라 60초 | 6.791초 | 13.387초 | 73.544초 | 85.752초 | 8245.44MiB | 12438.95MiB |
| 서연 60초 | 5.917초 | 11.787초 | 58.216초 | 70.486초 | 8245.44MiB | 12452.30MiB |
| 아라 120초 | 5.966초 | 14.851초 | 81.146초 | 97.706초 | 8783.65MiB | 12502.48MiB |
| 서연 120초 | 7.038초 | 17.441초 | 89.279초 | 105.539초 | 8783.65MiB | 12516.93MiB |

네 작업 모두 NAS 보관 완료. WAV·MP3 총 8개를 다시 받아 크기·SHA-256 일치, 전체 PCM 디코딩, 유한 값, 피크, 요청 길이를 검증했다. 모두 48kHz 스테레오이며 정확히 60초 또는 120초다. 생성+변환 시간은 Worker의 두 단계 합이며 인코딩·큐 대기·NAS 전송은 NAS 접수→보관 시간에 포함된다. CUDA·RAM 값은 원곡 생성 단계 측정 범위이며 전체 변환 파이프라인의 최대치로 해석하지 않는다.

음원과 요청 가사·측정 보고서는 로컬 `artifacts/free-long-persona-2026-10-10/`에 저장했다. 이번 장시간 검증은 NAS API 경로로 실행했고 Grok UI 재생을 별도 반복하지 않았다. 60초·120초 발음·음색·길게 유지되는 음의 자연스러움은 사용자 청취 평가 전이며 자동 검사 통과와 구분한다.
