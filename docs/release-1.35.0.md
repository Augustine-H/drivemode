# 보이스 그록 1.35.0

보컬 노래 생성에서 아라·서연 페르소나를 선택할 수 있다. 무료 ACE-Step 또는 유료 ElevenLabs 원곡을 생성한 뒤 PC에서 보컬을 분리하고 Seed-VC로 선택한 음색을 변환해 반주와 합친다. 기본 생성 공급자는 계속 무료 로컬이다. ElevenLabs는 비용 동의가 있어야 호출하며 페르소나 참조 음성을 전송하지 않는다.

음색 변환은 기존 Windows GPU 작업 큐에서 순차 실행한다. 필요한 모델·참조 파일이 없는 목소리는 선택을 차단하고 다른 목소리로 대체하지 않는다. 유료 원곡·호출 기록을 보존하며 변환 실패 때문에 유료 생성을 자동 반복하지 않는다. 원곡 생성 후 취소하면 변환을 건너뛴다. 변환 중 취소하면 완료된 음원을 보존한다.

## 검증과 한계

- 사용자 청취에서 ElevenLabs 원곡과 아라·서연 변환본이 같은 평가 구간에 대해 수용됐다. 곡·음역별 동일 품질이나 xAI 음색의 완전한 재현을 보장하는 결과는 아니다.
- 이전에 구매한 30.0408초 원곡으로 새 Worker 큐 경로를 검증했다. 유료 호출 부분만 명시적인 진단 파일 재생으로 대체했고 실제 분리·CUDA 음색 변환·반주 합성·MP3 인코딩을 실행했다. 아라 35.64초, 서연 35.36초; Seed CUDA 할당 메모리 최대 2712.03/2716.53MiB. WAV·MP3 전체 디코딩 및 유한 값 검사 통과. 이 검증의 신규 유료 API 호출·추가 비용은 0이다.
- 유료 요청 동의, API·웹앱 규약, 취소, 변환 실패 시 원곡 보존과 자동 재호출 방지, 누락된 변환 메타데이터로 원곡이 덮어써지지 않는 것을 테스트했다.
- 무료 직접 참조 가창과 공개 DiffSinger 목소리는 청취 품질을 통과하지 못해 운영 기본 경로로 채택하지 않았다. RVC와 관련 진단·학습 도구는 연구용이며 현재 운영 변환은 Seed-VC다. 페르소나별 가창 데이터 학습은 준비된 검수 데이터가 없어 완료되지 않았다.
- 인증 키는 기존 DPAPI 로컬 저장 방식으로 관리한다. GitHub 소스에 음성 참조·학습 자료·모델 가중치·인증 파일을 포함하지 않는다. NAS는 큐와 음원 보관을 담당하며 생성·변환은 Windows Worker가 수행한다.

상세 실험과 준비 조건은 [Persona Singing Voice v1 기록](./persona-singing-voice-v1-local-prototype.md)을 참고한다. 새 버전의 최종 테스트·게시 결과는 아래에 기록한다.

## Grok 무료 가창 실사용 검증 · 2026-10-10

사용자 승인 후 기존 NAS 연결 키를 Grok 브라우저의 암호화 저장소에 등록했다. 임시 연결 파일은 가져오기 직후 제거했고 새로고침 후에도 연결·완성 작업이 유지됐다. 기본 생성 모델은 무료 로컬을 유지했다.

Grok의 실제 생성 메뉴로 동일한 한국어 가사·분위기의 30초 작업을 아라와 서연에 각각 요청했다. 별도 원곡을 생성한 기능 검증이며 동일 원곡을 이용한 두 음색 비교 실험은 아니다.

| 목소리 | Worker 생성·변환·인코딩 | NAS 접수부터 보관 완료 | 로컬 음색 변환 |
| --- | ---: | ---: | ---: |
| 아라 | 70.493초 | 86.128초 | 47.640초 |
| 서연 | 69.196초 | 81.937초 | 47.344초 |

양쪽 WAV·MP3를 NAS에서 다시 받아 크기·SHA-256을 확인했다. 모두 30초·48kHz·2채널이며 전체 디코딩·유한 PCM·피크 검사 통과. Grok 앱 라이브러리에 양쪽 WAV를 저장했고 각 음악 카드의 실제 오디오 재생 시간이 진행되는 것을 확인했다. 추가 유료 호출은 0이다. 이 30초 출력은 이후 사용자 청취에서 “괜찮네”로 수용됐다. 곡·길이가 달라진 출력은 별도 청취 평가가 필요하다.

CUDA 할당 최대는 각 8091.75MiB, 프로세스 RAM 표본 최대는 아라 12364.16MiB·서연 12419.14MiB였다. 음원·검증 보고서는 로컬 `artifacts/grok-free-singing-1.35.0/`, 재생 증거는 `screenshots/grok-free-1350-ara-playing.png`와 `screenshots/grok-free-1350-eve-playing.png`에 보관한다.

## 동일 원곡 비교 및 Grok 장시간 실사용 검증 · 2026-10-10

위 60초 아라·서연 작업의 변환 전 원곡 SHA-256과 분리 보컬 SHA-256이 각각 동일함을 확인했다. 두 변환은 서로 다른 페르소나 참조를 사용했다. 기존 완성 변환본으로 동일 원곡 비교 음원을 구성했으며 신규 원곡 생성·유료 호출은 하지 않았다. 별도 진단 변환 시도는 실행 중인 Worker의 GPU 잠금에 막혀 추론 전에 중단됐으며 잠금 우회·Worker 중단 없이 기존 검증 출력으로 비교했다. 비교 결과와 원곡은 로컬 `artifacts/same-source-persona-2026-10-10/`에 보존했다. 사용자에게 비교 음원을 제공하며 음색 구분 평가는 아직 남아 있다.

Grok 실제 게시 웹앱에서 무료 공급자와 페르소나 옵션을 선택하고 서연 60초, 아라 120초를 각각 새로 생성했다. 양쪽 모두 생성 중 새로고침 후 동일 NAS 작업 ID를 복구했고 중복 작업 없이 완료됐다.

| 웹앱 요청 | 생성+변환 | NAS 접수→보관 | NAS 작업 ID |
| --- | ---: | ---: | --- |
| 서연 60초 | 59.173초 | 70.440초 | `8f40ca65-416d-4443-9fa6-ec9bb1c6c79f` |
| 아라 120초 | 84.302초 | 99.714초 | `4c424950-f777-4723-ac01-246887e12d07` |

WAV·MP3 모두 NAS에서 다시 받아 크기·SHA-256 일치, 요청 길이, 전체 PCM 디코딩·유한 값·피크를 확인했다. 음악 카드에서 WAV 앱 저장 성공을 확인하고 실제 오디오 재생 시간이 서연 10.15초, 아라 11.10초까지 진행됐으며 오디오 오류는 없었다. 음원·가사·측정 보고서는 로컬 `artifacts/grok-web-long-persona-2026-10-10/`에 보존했다. 재생 증거는 `screenshots/grok-web-eve-60-playing.png`와 `screenshots/grok-web-ara-120-playing.png`다. 신규 유료 호출은 0이고 기능 코드·버전 변경 없이 검증과 사용 안내를 보강했다.

사용자 청취에서는 앞선 무료 장시간 출력이 긍정적으로 평가됐다. 특정 발음·후반부 모든 음의 품질을 개별 검수했다는 뜻은 아니며 새 웹앱 출력과 같은 원곡의 두 음색 비교는 별도 청취 평가 대상으로 둔다. [페르소나 가창 사용 안내](./persona-singing-user-guide.md)에 무료·유료 선택, 실측 대기 시간, 저장·재생과 품질 확인 방법을 정리했다.

완성 후 새로고침해도 양쪽 작업 카드가 유지됐고, 앱 라이브러리에 WAV·MP3 로컬 원본이 남아 있었다. 60초 WAV 17,280,044바이트·MP3 2,401,964바이트, 120초 WAV 34,560,044바이트·MP3 4,801,964바이트다. 라이브러리 복구 증거는 `screenshots/grok-web-eve-60-library-restored.png`와 `screenshots/grok-web-ara-120-library-restored.png`이며 최종 브라우저 오류·경고 기록은 없었다. 앱의 기존 임시 30일 보존 설정은 유지했다.

## 음색 구분 강화 후보 · 2026-10-10

동일 원곡 아라·서연 비교에 대한 사용자 평가는 “자세히 들으면 구분됨”이었다. 분명한 음색 차이까지 승인된 결과로 해석하지 않는다. 후속 승인에 따라 같은 분리 보컬·참조·음높이·시드·30 diffusion steps를 유지하고 Seed-VC CFG를 기존 0.7에서 0.9·1.0으로 바꾼 네 변환 후보를 만들었다. CFG는 전체 조건 가이던스 조절값이며 목소리 차이만 선형으로 증가시키는 전용 수치는 아니다. 개선 판정은 청취 평가가 필요하다.

| CFG | 아라 변환 추론 | 서연 변환 추론 |
| --- | ---: | ---: |
| 0.9 | 19.156초 | 19.359초 |
| 1.0 | 19.068초 | 18.885초 |

네 완성 WAV·MP3는 모두 60초·48kHz·2채널로 전체 디코딩·유한 PCM·피크·길이 검사를 통과했다. 추론은 공통 원곡 보컬 SHA-256을 확인했고 참조는 기존 아라·서연 각각을 유지했다. 대기 중 Worker와 bridge를 잠시 정지한 뒤 기존 GPU 잠금으로 순차 실행하고 finally에서 자동 시작 경로로 복구했다. 복구 종료코드 0, 인증 health acceptingJobs=true·activeJobId=null·error=null을 확인했다. 새 모델·유료 API 호출·운영 기본값 변경은 없다.

후보와 결과 보고서는 로컬 `artifacts/persona-distinction-2026-10-10/`에 보존했다. 청취 편의를 위해 기존 0.7과 새 0.9·1.0 각각의 동일 10~30초 구간을 아라 20초 → 1초 침묵 → 서연 20초 순으로 연결했다. 모든 비교 프리뷰에 같은 gain을 적용하고 시간 늘이기는 하지 않았다. 발음·자연스러움·음색 구분의 최종 평가는 대기 중이며 운영 기본 CFG 0.7을 유지한다.
