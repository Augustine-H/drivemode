실제 마이크로 녹음한 Pretender 30초를 Qwen과 세 유료 API에 동일하게 입력했다. 사용자가 시작과 마지막 불완전 구절을 추론 전에 확인했고, 정답·채점 코드·음원 해시를 고정했다. 마지막은 완성 문장으로 보충하지 않았다. 엄격 CER의 정답 길이는 정규화 후 96문자다.

CER은 낮을수록 좋다. 엄격 CER에는 한자·가나·영문 표기 차이도 포함된다. 표의 백분율은 소수 둘째 자리까지 표시했고 정확한 오류 개수는 함께 보존했다. Qwen 내부 모델 처리 시간은 13.674초이며 표의 17.684초는 전체 요청 시간이다. 한 번씩 측정한 지연 시간이며 평균이나 보장 지연 시간이 아니다.

## 입력과 실행 검증

- 실제 브라우저 getUserMedia의 Samson Go Mic 입력이다. 디지털 음원으로 대체하지 않았다.
- 동일한 WAV: 30.000초, 16 kHz, 모노 PCM16. RMS -23.7 dBFS, 피크 -5.1 dBFS, 클리핑 비율 0이다.
- 세 유료 요청 모두 HTTP 200. 공급자별 1회, 재시도·자동 대체·곡명이나 정답 가사 힌트 없이 실행했다.
- 키는 로컬 Windows 사용자 인증 저장소에서 복호화했다. 원본 녹음·정답 전문·응답 전문·키는 Git에 포함하지 않는다.
- 표시 단가에 따른 이번 세 요청 비용 추정은 $0.004917이다. 실제 청구액은 확인하지 않았다.

## 표기 진단의 한계와 발견한 오류

제한적인 표기 진단은 추론 전에 정한 두 규칙만 적용한다: 영어 I'm sorry의 가타카나 표기와 一人/ひとり 표기 동등성이다. 완전한 발음 동등성 평가가 아니다. 특히 고정한 정규식의 Unicode 단어 경계 때문에 ElevenLabs 결과의 일본어에 바로 붙은 영문 I'm sorry가 치환되지 않았다. 결과를 본 뒤 규칙을 변경하거나 점수를 다시 유리하게 계산하지 않았다. 이 점수만으로 공급자의 청취 성능 차이를 단정하지 않는다.

별도로 사전 고정한 pykakasi 2.3.0 히라가나 진단은 검산 중 줄바꿈 처리 오류가 확인돼 **비교 및 추천 판단에서 제외했다**. 독립 재현 입력 `ねこ\nいぬ`는 기대값 `ねこいぬ` 대신 `ねこねこいぬ`를 출력했다. 줄바꿈 전 가나가 중복돼 정답 및 응답의 줄 구성에 따라 오류율이 왜곡된다. 원시 진단 점수와 사전 고정 정책은 JSON에 보존하고 `validForComparison: false` 및 `PYKAKASI_NEWLINE_KANA_DUPLICATION`으로 표시했다. 수정된 진단의 재채점은 수행하지 않았다. 원래 엄격 CER과 위 제한적인 표기 진단에는 이 변환기를 사용하지 않는다.

## 적용 판단

이 녹음에서는 OpenAI의 고정 정답 대비 문자 오류가 Qwen보다 2개 적었다. 한 곡의 한 구간이고 표기 차이가 포함되므로 일반적인 일본어 가창 우위나 모델 교체 근거로 확대하지 않는다. 한국어·영어·일본어 실제 마이크 비교가 모두 완료됐으며, 기본 Qwen과 제품 1.28.2를 유지한다. 유료 자동 호출은 추가하지 않았다.
