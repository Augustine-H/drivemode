# 음악 듣기 연결

설정의 **지금 나오는 곡 · 음량·박자 분석**에서 12초 듣기를 시작한다.
채팅의 “지금 나오는 곡 알려줘”도 같은 기능을 연다.

- **곡 이름도 찾기 끔:** 마이크 입력의 평균 dBFS와 추정 BPM을 기기에서 계산한다. 녹음은 저장하거나 외부로 보내지 않는다.
- **곡 이름도 찾기 켬:** 12초 녹음을 서버를 거쳐 AudD로 보내 곡명·가수를 확인한다. 서버 키가 없거나 곡을 찾지 못하면 이유와 로컬 분석 결과를 표시한다.
- 듣기 중지, 메인 멈춤 버튼, 설정 닫기로 취소할 수 있다. 취소 후 늦게 도착한 결과는 대화에 추가하지 않는다.

## 곡 찾기 활성화

1. [AudD 대시보드](https://dashboard.audd.io/)에서 서비스 키를 만든다.
2. 게시 서버의 **비밀 환경 변수**에 `AUDD_API_TOKEN`이라는 이름으로 등록한다. 클라이언트용 `VITE_` 변수나 코드·GitHub·대화에 키를 넣지 않는다.
3. 다시 게시한 뒤 곡 찾기를 켜고 테스트한다. Grok 게시 환경에서 별도 비밀 변수 등록을 지원하지 않으면 이 서버 연결은 해당 환경에서 활성화할 수 없다. 설정의 Shazam 열기를 사용할 수 있다.

AudD 인식은 별도 서비스의 사용량·요금에 따른다. xAI 대화나 음성 API를 사용하지 않는다.
[공식 API 문서](https://docs.audd.io/)의 Standard Recognition을 사용하며 요청은 버튼·채팅 명령당 한 번이다.

## 분석 범위

다른 앱의 재생 정보를 읽는 기능이 아니다. 마이크에 들리는 주변 소리를 분석하므로 이어폰 속 음악은 잘 잡히지 않을 수 있다.
dBFS는 마이크 입력 기준이며 보정된 소음계의 dB SPL이 아니다. 자동 이득 조절·기기 특성에 영향을 받는다.
BPM은 12초 입력의 에너지 변화로 추정한다. 목소리·내비·잡음·약한 비트는 인식에 영향을 주며 박자를 반 또는 두 배로 추정할 수 있다.
영상 질문의 분석은 별도로 시작·중간·끝 장면만 사용하고 영상 소리를 분석했다고 주장하지 않는다.
