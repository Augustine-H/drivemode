# 1.30.0 선택형 유료 음악·보컬 생성

설정 → 음악 생성 · NAS 연결 → 음악·보컬 생성 모델 선택에서 로컬 또는 ElevenLabs Music v2.5를 선택한다. 연주곡 만들기와 보컬 노래 만들기에 같은 선택값을 적용한다. 기본은 로컬이고, 채팅·음성 명령은 자동으로 유료 공급자를 선택하지 않는다. 설정에서 생성하는 길이는 10~120초이며 기존 채팅의 로컬 연주곡 1~120초 지원은 유지한다.

유료 생성은 설명·직접 쓴 가사의 외부 전송과 유료 호출에 명시적으로 동의해야 제출할 수 있다. 공급자·설명·가사·길이를 변경하면 동의를 초기화한다. NAS에 가격 정보나 공급자 연결이 없으면 유료 제출을 차단한다. 키 등록 여부는 음악 API 이용 권한이나 유료 구독 확인을 의미하지 않는다.

연주곡은 `force_instrumental=true`와 정확한 길이를 보낸다. 보컬곡은 `music_v2_5`의 단일 chunk composition plan에 가사, 스타일, 길이와 seed를 보낸다. 가사는 최대 4,000자다. 공급자에 계획 생성 API를 추가로 요청하지 않는다. 키는 기존 Windows DPAPI 등록 또는 Worker 프로세스 환경변수에서만 읽으며 NAS나 브라우저에 보내지 않는다.

유료 생성은 GPU 모델 로딩을 거치지 않는다. 요청 전 독점 생성하고 디스크에 동기화한 `paid-generation-call.json`으로 작업별 한 번만 전송한다. HTTP 오류나 타임아웃 시 자동 재시도·다른 공급자 전환은 하지 않는다. 네트워크 오류 때 실제 과금 여부는 불확실하다. 전송 후 취소는 공급자의 과금이나 생성을 되돌리지 못하며 로컬 완료 후 미리보기 생성을 중단한다.

공급자 응답 MP3를 Windows의 `provider-original.mp3`에 보존하고 모든 프레임을 디코딩해 스테레오·비무음·길이를 검증한다. 이 MP3를 WAV로 디코딩해 NAS에 저장하고 앱 재생용 320 kbps MP3를 생성한다. WAV는 무손실 생성 원본이 아니며 재인코딩은 음질을 높이지 않는다. NAS에는 WAV와 재생용 MP3를 기존 경로로 저장한다. 라이브러리 메타데이터에 ElevenLabs와 실제 모델명을 기록한다.

표시 단가는 2026-10-06 공식 가격 $0.15/분 기준 추정으로 30초 $0.075, 120초 $0.30이다. 실제 청구액·계정 요금제·세금·과금 단위와 다를 수 있다. [가격](https://elevenlabs.io/pricing/api), [Compose API](https://elevenlabs.io/docs/api-reference/music/compose), [composition plan](https://elevenlabs.io/docs/eleven-api/guides/how-to/music/composition-plans), [유료 사용자 요건](https://elevenlabs.io/docs/eleven-api/guides/cookbooks/music)을 참고한다.

## 검증 상태

- Python 84개, TypeScript 13개 테스트와 typecheck, production build 통과.
- 개발·프로덕션 데스크톱/모바일 렌더링, 콘솔 오류 및 가로 넘침 검사 통과.
- 실제 NAS `paid-1300` 이미지 빌드·서비스 시작과 Windows/bridge 연결 갱신 완료. NAS는 로컬 및 ElevenLabs 생성 공급자를 광고한다.
- 앱에서 공급자 선택·가격 표시, 동의 전 제출 차단, 설명 수정 시 동의 초기화를 확인.
- HTTP mock으로 단일 요청·타임아웃·중복 차단·취소 전 무전송·실패 후 Worker 정상 상태를 확인. 실제 테스트용 MP3의 원본 보존·WAV 디코딩 파이프라인도 검증.
- 최초 무료 플랜 테스트의 연주곡·보컬곡 두 요청은 HTTP 402 / limited_access로 실패했다. 산출물이 없었고 자동 재시도·구독 변경·모델 우회를 하지 않았다. 사용자가 직접 결제 후 계정의 Starter 활성화를 확인했다.
- Starter 활성화 후 실제 앱에서 새로운 30초 연주곡·한국어 보컬곡을 각각 한 번 호출했고 모두 HTTP 200으로 성공했다. 공급자 생성부터 WAV 디코딩까지 연주곡 9.079초, 보컬곡 4.484초였다. NAS 큐 대기·업로드·브라우저 폴링 시간은 이 측정에 포함되지 않는다.
- 두 음원 모두 44.1 kHz 스테레오, 30.040816초이다. WAV는 PCM 24-bit이며 공급자의 MP3를 디코딩한 파일이다. 재생용 MP3 320 kbps 변환 성공. WAV·MP3의 모든 프레임 디코딩, 비무음·유한 값, NAS 다운로드와 저장 메타데이터 SHA-256 일치를 확인했다.
- 한국어 보컬은 정답 가사를 추론에 제공하지 않고 기존 로컬 Qwen Worker로 추가 확인했다. 여섯 줄의 한국어 내용이 대부분 인식됐고 정규화 문자 오류율(CER)은 5/67 = 7.46%였다. 창가/참가, 걸어가/걸어다, 나를/날을 및 마지막 추가 글자 등 차이가 있다. 이 값에는 받아쓰기 모델 오인식도 포함되므로 생성 모델의 발음 정확도나 청감 품질 점수가 아니다. 음원은 외부 받아쓰기 API에 전송하지 않았다.
- 성공한 두 생성 요청의 표시 단가 기준 예상 비용은 총 $0.15이며 실제 청구액은 미확인이다. [실제 테스트 집계](./paid-music-generation-1300-test.json).

- 실제 재생 검증에서 미디어 저장소의 갱신 알림이 변경 없는 파일까지 다시 로드해 재생 위치를 초기화하는 문제를 발견했다. ManagedMedia는 fileRevision·checksum·storageKey·크기·MIME이 같으면 기존 object URL을 유지한다. 비동기 갱신 순서를 확인해 이전 읽기 결과가 새 상태를 덮어쓰지 않게 했으며, 삭제·휴지통·누락 상태에서는 기존 원본을 계속 해제한다. 수정 후 연주곡과 한국어 보컬 모두 30.040816초까지 브라우저 재생을 완료했고 ended=true·media error 없음이 확인됐다. 연주곡 재생 중 상태 갱신 전후 8.087초→12.761초로 진행됐으며 같은 음원 소스·paused=false를 유지하는 회귀 검사도 통과했다.
- 수정 후 typecheck 및 production build 재통과. 기존 프로덕션 미리보기 서버 재시작은 자동 승인 검토의 정책상 차단으로 실행하지 않았다. 기존 미리보기는 이전 번들 정보를 캐시하므로 최신 빌드는 별도 loopback 8083 미리보기에서 검증했다. 개발·최신 빌드의 데스크톱/모바일 화면을 모두 시각 검사했고 콘솔 및 가로 넘침 검사와 baseline 비교를 통과했다. 기존 8081 프로세스는 유지됐다.
