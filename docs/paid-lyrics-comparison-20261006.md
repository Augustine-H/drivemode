# 한국어·영어·일본어 유료 가창 API 비교 실측

2026-10-06. xAI·OpenAI·ElevenLabs의 실제 요청 9회가 모두 HTTP 200으로 완료됐다. 같은 3개 PCM 파일을 각각 한 번씩 전송했고 자동 재시도·모델 대체·정답/곡명 힌트는 사용하지 않았다. 유료 결과는 실제 공급자 응답이며 앞선 MockTransport 검증과 구분한다.

이번 1차 비교에서는 영어 25초 음원에서 OpenAI의 엄격 단어 오류가 1개 줄었으나, 경로 간 차이는 모두 old/auld 표기 선택이었다. 청취 능력 자체의 개선으로 단정하지 않는다. 일본어는 엄격 표기 점수에서 Qwen이 가장 낮았으나, 영어/가타카나 표기 차이를 구분한 사후 분석에서는 Qwen·OpenAI·ElevenLabs가 동률이었다. 한국어는 사용자가 확인한 정확한 30초 정답 기준으로 Qwen과 ElevenLabs의 문자 오류율이 13.24% 동률이다. 단어 오류율은 ElevenLabs가 29개 중 1개 오류 적었지만 한 음원의 작은 차이다. 전체 기본 모델 교체나 제품의 자동 유료 호출은 적용하지 않았으며 버전은 1.28.2다.

## 정확도

오류율은 낮을수록 좋다. 영어는 WER, 일본어는 엄격 CER이다. 한국어는 사용자가 실제 30초 녹음의 정답을 확인했고, 끝에서 잘린 단어도 그대로 포함해 전체 출력과 비교했다. 정답은 첫 추론 뒤에 확정됐으며 모델에 전달하지 않았다. 별도의 원어민 독립 청취 검수와 구분한다.

| 경로 | 영어 WER · 21단어 | 일본어 엄격 CER · 104자 | 한국어 CER · 68자 |
|---|---:|---:|---|
| 현재 Qwen 제품 경로 | 4.76% · 오류 1개 | 4.81% · 오류 5개 | 13.24% · 오류 9개 |
| xAI grok-voice-transcribe-2.0 | 4.76% · 오류 1개 | 6.73% · 오류 7개 | 23.53% · 오류 16개 |
| OpenAI gpt-transcribe | 0% · 오류 0개 | 11.54% · 오류 12개 | 27.94% · 오류 19개 |
| ElevenLabs Scribe v2 | 9.52% · 오류 2개 | 11.54% · 오류 12개 | 13.24% · 오류 9개 |

한국어 보조 WER은 Qwen 31.03%(오류 9/29), xAI 44.83%(13/29), OpenAI 44.83%(13/29), ElevenLabs 27.59%(8/29)다. 띄어쓰기와 단어 경계의 영향을 받는 보조 지표이며 주 CER 동률을 전체 품질 향상으로 바꾸어 주장하지 않는다.

### 영어 표기 차이 진단 — 사후 보조 분석

고정 영어 정답은 일반 구절의 old와 제목 구절의 auld를 사용했다. Qwen·xAI는 제목 구절을 old로, ElevenLabs는 앞의 두 일반 구절도 auld로 출력했다. 나머지 21단어의 순서·내용은 같았다. 따라서 엄격 WER 0%/4.76%/9.52%의 차이는 모두 이 방언/철자 선택에서 발생했고 실제 청취 성능 향상으로 확대하지 않는다.

결과를 본 뒤 old/auld 전체 단어만 동일하게 취급한 사후 진단에서는 네 경로 모두 WER 0%다. 고정 주 정답과 엄격 점수는 바꾸지 않았다. 이 작은 민요 자료와 표기 차이만으로 유료 모델 도입을 권하지 않으며, 독립 현대곡의 원어민 검수 정답을 추론 전에 고정해야 한다.

### 일본어 표기 차이 진단 — 사후 보조 분석

원문 가타카나 `アイムソーリー`를 OpenAI·ElevenLabs는 영문 `I'm sorry`/`I’m sorry`로 출력했다. 엄격 CER에는 이 차이가 포함되므로 점수가 곧 동일 수의 청취 오류라는 뜻은 아니다.

보조 분석은 기존에 사용한 `一人`/`ひとり` 표기 동등성과, **이번 출력을 본 뒤 추가한** 정확한 영문 `I'm sorry`/`I’m sorry` → `アイムソーリー` 치환만 사용했다. `人生柄`/`人生から` 및 잘못 인식한 `アイムストーリー`는 동등하게 바꾸지 않았다. 정답에 유리한 일반 발음 변환·문장 수정·LLM 보정은 하지 않았다. 사후 기준이므로 주 점수를 대체하거나 독립 개선 증거로 사용하지 않는다. 다음 독립 음원 평가에서는 이 기준을 추론 전에 고정해야 한다.

|---|---:|
| Qwen | 1.92% · 오류 2개 |
| xAI | 3.85% · 오류 4개 |
| OpenAI | 1.92% · 오류 2개 |
| ElevenLabs | 1.92% · 오류 2개 |

## 실제 요청 처리 시간

단위는 초이며 요청 시작부터 응답 완료까지의 단일 측정이다. 유료 API는 네트워크·원격 처리를 포함한다. Qwen 첫 한국어 요청에는 모델 초기 로딩이 포함되므로 세 서비스의 내부 GPU 추론 시간과 직접 비교하지 않는다. 공급자의 RAM/VRAM은 관측할 수 없으며 값을 만들지 않았다.

## 입력과 요청 조건

한국어는 사용자 실제 녹음, 영어는 Auld Lang Syne의 기존 25초 구간, 일본어는 Pretender의 사용자 35.968초 녹음이다. 언어당 1개 파일, 공급자당 1회뿐이라 일반적인 가창 성능이나 통계적 유의성을 주장하지 않는다. 영어 민요 결과를 현대 팝 믹스에 일반화하지 않는다. 일본어 정답은 사용자 원문이며 별도의 원어민 청취 검수는 미실시다.

모든 입력은 메타데이터를 제거한 16 kHz 단일 채널 PCM16이고 각 경로의 동일 SHA-256을 확인했다. API 파일명도 곡명 없는 `sample-ko.wav` 등의 이름을 썼다. Qwen은 실제 제품 경로에서 언어 명시, fullFile=true, identify=false로 실행했다. 제품의 내부 구간 분할/필터와 공급자의 원본 출력 차이가 있는 실사용 경로 비교이며 모델 구조만 통제한 실험은 아니다.

- xAI: `grok-voice-transcribe-2.0`, `/v1/stt`, 언어 지정·format=false, file 필드를 마지막에 전달. [공식 API](https://docs.x.ai/developers/model-capabilities/audio/speech-to-text).
- OpenAI: `gpt-transcribe`, `/v1/audio/transcriptions`, `languages[]` 사용. prompt·keywords·singular language는 보내지 않았다. [공식 파일 받아쓰기](https://developers.openai.com/api/docs/guides/speech-to-text).
- ElevenLabs: `scribe_v2`, `/v1/speech-to-text`, language_code 지정. 음향 태그·diarization 비활성, keyterm·entity·transcript_edit 유료 옵션은 사용하지 않았다. [공식 API](https://elevenlabs.io/docs/api-reference/speech-to-text/convert).

## 비용과 인증

서비스당 90.968초, 전체 9회다. 표시 단가 xAI $0.10/시간, OpenAI $0.27/시간, ElevenLabs $0.22/시간을 곱한 기본 추정은 총 약 $0.014909다. OpenAI 응답의 duration usage는 30·25·36초로 합계 91초였으며 이를 사용한 단가 추정 합계는 약 $0.014911다. 공급자별 표시 단가와 usage를 실제 최종 청구액으로 간주하지 않는다. 세금·가입 요금·최소 과금·계약 조건은 별도이며 계정 청구 내역은 확인하지 않았다.

[xAI 가격](https://docs.x.ai/developers/models/speech-to-text), [OpenAI 가격](https://developers.openai.com/api/docs/pricing), [ElevenLabs 가격](https://elevenlabs.io/pricing/api).

사용자가 세 API의 등록을 완료한 뒤 실행했다. 키는 이 PC의 Windows 사용자에 묶인 DPAPI 저장소에서 읽고 값은 화면·로그·소스·Git에 출력하지 않았다. 인증 등록 여부와 실제 HTTP 200으로 접근을 확인했다. 요청 길이/회수/추정 비용 제한과 중복 요청 원장을 적용했으며 재시도는 0회다. 음원은 사용자가 요청한 비교를 위해 세 공급자에게 전송됐다. Git에는 집계값만 저장한다. 전체 정답 가사·공급자 원문 출력의 로컬 보관본·평가 음원 파일·API 키는 커밋하지 않았다.

## 적용 판단과 남은 확인

현재 Qwen을 유지한다. 영어의 단일 단어 개선과 일본어 표기 차이만으로 자동 유료 fallback을 도입하지 않는다. 한국어 점수도 사용자가 확인한 실제 구간으로 마무리했다. 다음 단계는 정답을 추론 전에 고정한 독립 한국어·영어·일본어 현대곡과 실제 마이크의 짧은 구간을 추가 비교하는 것이다. 유료 경로는 이번 단일 요청에서 빠르게 응답했으므로 지연 시간 우선의 수동 선택 후보로 검토할 수 있다. 다만 영어의 표기 차이, 일본어 사후 동률, 한국어 주 CER 동률은 기본 정확도 모델 교체 근거가 부족하다. 독립 현대곡에서 실제 단어 누락/오인식 감소를 먼저 확인해야 한다.
