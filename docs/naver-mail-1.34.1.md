# 네이버 한글 검색 보완 · 1.34.1

1.34.0 운영 실메일 검증에서 INBOX 최근 목록에는 있는 테스트 메일이 전체 한글 제목 및 `보이스` 검색에는 나오지 않았다. 기존 경로가 IMAP TEXT 검색 결과만 사용하던 것을 보완해, 기존 서버 검색 결과에 최근 100통의 디코딩된 제목·보낸 사람 비교 결과를 합친다. 부분 서버 결과가 있어도 보완하고 중복을 제거해 UID 기준 최근 20통을 표시한다. 한글 조합형/완성형, 대소문자와 전각 문자를 정규화하며 안읽음 필터를 유지한다.

추가 확인은 최근 100통의 제목·보낸 사람에 한정된다. 본문 및 오래된 메일은 기존 IMAP 서버 검색 결과를 사용하므로 서버의 본문 검색 누락까지 해결했다고 주장하지 않는다. 검색 중 원문·첨부를 다운로드하거나 읽음 플래그를 변경하지 않는다. 화면에 보완 범위와 본문 검색의 범위를 표시한다. 서버 내부의 한글 인덱싱 원인은 직접 확인하지 않았다.

검증: 검색 회귀 테스트 5개 및 기존 네이버·Google·NAS/인증 테스트 32개, 총 37개 통과. 타입 검사, 기본 Vercel/NAS 빌드 및 개발·두 빌드의 데스크톱/모바일 smoke 검사 통과. 모든 화면을 직접 확인했고 가로 넘침·콘솔/페이지 오류가 없다. 테스트는 서버가 결과를 전혀 주지 않는 경우, 부분 결과·중복, 한글 정규화·보낸 사람, 안읽음, 최근 범위·20통 상한 및 오래된 서버 결과 보존을 확인한다.

패키지: `artifacts/voice-grok-web-1.34.1-search.zip`, SHA-256 `9db78966a0ce25995e61e7935e326a63e0c9a286d85672953dea9ade26af850c`. 기존 비활성 작업을 `VoiceGrok Naver Search Fix 20261009`로 변경해 사용자가 DSM 재인증을 완료한 뒤 실행했다. 이전 앱/compose/start 보관과 실패 시 복원 경로는 `naver-backup-20261009-1341`이다. 작업 완료 및 실계정 검색 결과는 후속 확인 중이다. 비밀번호는 열람하지 않고 기존 네이버/Google 저장소와 인증 설정을 유지한다.

2026-10-09 사용자의 후속 진행 요청으로 기존 기능 확인용 메일에 답장 1통, 전달 및 첨부 테스트 1통을 연결된 본인 주소로 발송했다. 두 건 모두 최종 미리보기에서 수신자·제목·본문·첨부를 확인하고 한 번씩 실행했으며 SMTP 접수 성공 후 INBOX에서 실제 도착을 확인했다. 답장은 14:50:17 KST, 전달은 14:50:55 KST를 표시했다. 답장 본문이 작성한 문구와 일치하고 전달 메일에 추가 문구 및 기존 테스트 원문이 모두 포함됐다. 받은 원문과 무관한 실제 개인 메일은 전달하지 않았다.

전달 초안에 기능 확인용 `naver-mail-test-attachment-20261009.txt` 한 개(발송 미리보기 156 bytes)를 직접 첨부했다. 수신 메시지의 첨부 목록에 같은 파일명이 표시되는 것을 확인했다. 후속 공식 웹메일 다운로드에서 수신 파일의 바이트 및 SHA-256가 원본과 일치했다(아래 참조). 현재 앱의 첨부 목록은 이름만 표시한다. 원본 첨부 자동 전달은 제공하지 않는다. 새로 보낸 테스트 메일은 두 통이며 중복/재시도 발송은 없다. 메일 삭제·이동·읽음 변경은 하지 않았다. 브라우저 오류 로그는 비어 있었으며 증빙은 `screenshots/naver-forward-attachment-received.png`이다.
