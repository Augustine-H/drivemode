# 채팅 하단 여백 수정 — 1.34.7

맨 아래 이동 버튼을 위해 추가했던 하단 패딩 80px을 기존 기본 여백 16px로 되돌렸다. 버튼은 채팅 영역 오른쪽 아래에서 말풍선 위에 겹치는 위치를 유지한다. 긴 대화에서 맨 아래로 이동하면 마지막 말풍선과 채팅 영역 바닥 사이의 간격은 16px이다.

타입 검사, 기본 Vercel 빌드, NAS 빌드 통과. PC·모바일에서 검색·결과 이동·맨 아래 이동과 마지막 말풍선의 하단 간격 16px을 검증했다. 개발 및 기본 운영 빌드 렌더링·콘솔·가로 넘침 검사 통과.

NAS 패키지: `artifacts/voice-grok-web-1.34.7-chat-spacing.zip`, SHA-256 `08a4fc85e2e275319193a19206f4ae94054276d8478a963295f7b89eee2db2ee`. 기존 파일과 이미지를 보존하며 실패 시 복원하는 스크립트: `artifacts/deploy-chat-1.34.7.sh`.
