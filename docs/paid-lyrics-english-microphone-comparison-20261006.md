# Samson Go Mic 실제 영어 노래 API 비교

2026-10-06. 사용자가 재생한 ‘Sign of the Times’를 Samson Go Mic로 30초 녹음하고 Qwen 제품 Worker와 xAI·OpenAI·ElevenLabs를 비교했다. 실제 유료 요청 3회 모두 HTTP 200으로 완료됐다. 사용자 확인 정답과 OpenAI 출력은 정규화 후 일치했고, 나머지 세 경로는 같은 위치에 `I` 한 단어를 추가했다. 작은 차이이며 기본 Qwen과 제품 버전 1.28.2를 유지한다.

## 입력과 사전 고정

브라우저의 현재 장치 목록에서 `마이크(Samson Go Mic) (17a0:0305)`를 명시적으로 선택했다. 실제 getUserMedia 장치 표시와 30초 자동 종료를 확인했다. 기존 제품 녹음 경로의 에코 제거·잡음 억제·자동 이득을 비활성화했고 음성 입력이 들어오는 것을 확인했다. 디지털 루프백이나 평가 파일로 실제 마이크 녹음을 대체하지 않았다.

브라우저가 생성한 원본 WebM을 동일 출처의 임시 내보내기 화면을 통해 이 PC에 보관했다. 임시 수신기는 127.0.0.1에만 바인딩하고 출처·Host·임의 경로·크기·WebM 헤더를 확인했으며 보관 뒤 종료했다. 원본을 메타데이터 없는 16 kHz mono PCM16 WAV로 변환하고 같은 해시의 파일을 네 경로 모두에 전달했다. 원본·변환 파일 해시는 집계 JSON에 기록한다.

| 입력 측정 | 결과 |
|---|---:|
| 길이 | 30.000초 |
| 평균 RMS | -32.5 dBFS |
| PCM 샘플 절대값 최대 | -14.7 dBFS |
| 절대값 ≥ 0.999인 샘플 비율 | 0% |

사용자가 제공한 7줄의 실제 시작·끝 구절을 **녹음 뒤, 첫 추론 전에 확인**했다. 정답 전체, 채점 정책, 평가 코드, 보조 축약형 진단 코드의 SHA-256을 고정하고 실행 시 검사했다. 결과를 본 뒤 정답을 수정하지 않았다. 사용자 확인 정답이며 별도의 원어민 독립 청취 검수는 미실시다. 전체 가사·음원·공급자 출력·API 키는 Git에 저장하지 않는다.

## 오류율과 처리 시간

단어 오류율은 낮을수록 좋다. 기존 제품 평가 함수의 NFKC/casefold 및 L/N/M 범주 정규화를 사용하며 누락·반복·추가 단어를 전체 출력에서 계산했다. 구두점과 어퍼스트로피는 단어 경계로 취급하므로 축약형 내부도 분리되며 정답 단위는 47개다. 보조 CER의 정답 단위는 169자다.

| 경로 | 주 WER · 47단위 | 보조 CER · 169자 | 요청→응답 시간 |
|---|---:|---:|---:|
| 현재 Qwen 제품 Worker | 2.13% · 추가 1개 | 0.59% · 추가 1자 | 17.367초 |
| xAI grok-voice-transcribe-2.0 | 2.13% · 추가 1개 | 0.59% · 추가 1자 | 1.822초 |
| OpenAI gpt-transcribe | 0% · 오류 0개 | 0% · 오류 0개 | 2.338초 |
| ElevenLabs Scribe v2 | 2.13% · 추가 1개 | 0.59% · 추가 1자 | 0.860초 |

Qwen·xAI·ElevenLabs의 차이는 모두 같은 위치, 정답 16단위 뒤에 `I` 한 단어가 추가된 것이다. 다른 단어의 대치·누락은 없었다. 세 경로에 공통으로 나타난 짧은 단어인 만큼, 실제 가창의 약한 발음이나 제공 정답의 생략 여부를 독립 청취 검수하지 않고 OpenAI의 청취 성능 우위를 확정하지 않는다. 고정 정답 대비 주 점수는 그대로 보존한다.

추론 전에 고정한 보조 진단은 `it's` → `it is`, `you're` → `you are`, `can't`/`cannot` → `can not`, `you ain't` → `you are not`만 양쪽에 동일하게 적용했다. 곡 내용·출력에 맞춘 문장 교정이나 일반 발음 동등성 치환은 없다. 이 진단에서도 각 경로 점수는 주 WER과 같았다. 즉 이번 차이는 축약형 철자에서 발생하지 않았다.

시간은 경로당 1회의 종단 측정이며 원격 API는 네트워크와 공급자 처리를 포함한다. Qwen 모델 처리 시간은 13.709초다. 프로세스 RAM·CUDA 표본은 집계 JSON에 보관하며 원격 공급자의 RAM/VRAM은 관측하지 않았다. 클리핑이 없다는 사실만으로 반주·잔향·방 잡음이 없다고 판단하지 않는다.

## 실제 호출과 비용

영어만 명시하고 중립 파일명 `sample-en.wav`를 사용했다. 모델에는 곡명·정답·가수·교정 프롬프트를 보내지 않았다. 요청 형식은 앞선 [실제 API 비교](./paid-lyrics-comparison-20261006.md)와 같고 자동 재시도·공급자 대체·Mock 응답은 없다. 중복 요청 원장과 최대 3회·추정 $0.10 제한을 적용했다. 사용자가 요청한 비교를 위해 이번 WAV를 세 공급자에게 실제 전송했다.

키는 기존 Windows 사용자별 DPAPI 저장소에서 읽고 소스·문서·Git에 저장하지 않았다. 공급자당 30초에 같은 표시 단가 xAI $0.10/시간, OpenAI $0.27/시간, ElevenLabs $0.22/시간을 곱한 이번 추가 기본 추정은 합계 **$0.004917**이다. 실제 계정 청구·세금·최소 과금·계약 요금은 미확인이다.

## 적용 판단

실제 영어 마이크 녹음에서도 네 경로의 출력은 거의 같았다. OpenAI가 사용자 정답과 일치했지만 차이는 한 단어이고 독립 청취 검수가 남아 있다. 언어당 한 곡·한 구간·한 번으로 일반적인 노래 인식 우위를 주장하지 않는다. 기본 Qwen을 유지하며 유료 경로의 빠른 응답은 수동 선택 후보의 근거로만 남긴다. Qwen 제품의 전처리/분할 경로와 공급자의 전체 입력 경로를 비교한 시험으로, 가중치만 통제한 비교는 아니다.
