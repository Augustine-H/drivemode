# 보이스 그록 1.36.1 · 외국어 가창 가사 분량 안내

무료 영어·일본어 보컬 입력에서 가사 행 수와 곡 길이에 맞춘 시험 시작 분량을 표시한다. 60초 8행·120초 16행은 경험적 안내이며 줄 길이·템포에 따라 달라진다. 입력한 가사를 자동으로 잘라내거나 고치지 않고 원어민 검수가 끝나지 않은 일본어를 정확도 통과로 표시하지 않는다. 기존 모델·CFG 0.9·한국어와 무료 기본값을 유지한다.

[가사 실험 기록](./foreign-singing-lyrics-density.md)에 무료 원곡 11개, NAS 페르소나 변환 4개와 변환 전후 전체 가사 분석을 기록했다. 일본어 30초 절 분할은 결과가 나빠 채택하지 않았다. 동일 가사·시드의 순서 유지 지시는 두 시드에서 차이가 있었지만 개선 폭이 달라 자동 적용하지 않는다. 신규 유료 호출은 0이다. 새 후보의 청취 승인과 독립 일본어 원어민 검수는 미완료다.

## 검증

- JavaScript 테스트 499개와 타입 검사 통과.
- Vercel·NAS 빌드 통과. 개발·NAS 빌드 출력 PC/모바일을 확인했고 콘솔 오류·가로 넘침이 없으며 본문은 일치한다.
- 생성 후보 11개 및 아라·서연 변환 4곡의 WAV/MP3 전체 디코딩·체크섬·길이·유한 PCM·피크 검증 통과.
- 원곡과 두 변환 요청의 원곡 해시 일치. 변환 CFG 0.9 확인.
- 실제 Grok 운영 입력 UI에서 영어 60초 10행 과다 안내, 일본어 120초 16행 권장 안내, 한국어에서 안내 미표시를 확인했다. 검증 입력은 지웠고 음악을 추가 제출하지 않았다.
- NAS·Grok 웹앱 기존 대화/작업 복원과 표시 버전 1.36.1, 브라우저 오류 로그 없음 확인.

대규모 모델·벤치마크 출력이 웹 빌드 파일 감시에 들어가지 않도록 감시 제외 대상을 보완하고 Tailwind 소스 탐색을 src 안으로 지정했다. 개발 서버 CSS 모듈 시간 초과를 해결한 뒤 두 화면을 다시 검증했다.
