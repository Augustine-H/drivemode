# 추가 한국어·영어·일본어 가창 API 실측

2026-10-06. 새 입력 3개로 Qwen 제품 경로와 xAI·OpenAI·ElevenLabs를 비교했다. 실제 유료 요청 9회가 모두 HTTP 200으로 완료됐고, 재시도·공급자 대체·정답 힌트는 없었다. 한국어에서는 ElevenLabs, 일본어에서는 xAI의 공개 주석 대비 오류율이 낮아졌다. 영어는 거의 동률이다. 앞선 실사용 녹음 결과와 함께 보면 개선은 음원과 언어에 따라 달라지므로 기본 모델을 교체하지 않았다. 제품은 1.28.2 그대로다.

## 새 입력과 사전 고정

사용자가 지정할 새 곡·정답은 없다고 답했다. [GTSinger 공식 자료](https://github.com/AaronZ345/GTSinger)의 사람 가창과 대응 주석을 사용했다. Yu Zhang 외, *GTSinger: A Global Multi-Technique Singing Corpus with Realistic Music Scores for All Singing Tasks*, NeurIPS 2024. [데이터](https://huggingface.co/datasets/AaronZ345/GTSinger), [데이터 이용 조건](https://github.com/AaronZ345/GTSinger/blob/main/dataset_license.md).

원본 revision은 `dc6c01fc093514f1e8137f98437328118c937128`이다. 아래 각 Control_Group의 전체 `0000.wav`·`0001.wav`·`0002.wav`를 순서대로 이어 붙이고 16 kHz mono PCM16으로 변환했다. 중간 무음을 추가하거나 가사 중간을 잘라 정답을 맞추지 않았다. **원래의 연속 상업 음원이 아니라 분할 녹음을 연결한 무반주 가창 자료**다. 원본·주석·변환 음원의 SHA-256을 집계 파일에 기록했다. 원본 음원과 전체 가사는 Git에 저장하지 않았다.

| 언어 | 자료 폴더 | 길이 | 주 채점 정답 단위 |
|---|---|---:|---:|
| 한국어 | KO-Soprano-1 / Breathy / all about you / Control_Group | 32.2986875초 | 54자 |
| 영어 | EN-Alto-1 / Breathy / let it go / Control_Group | 31.386초 | 47단어 |
| 일본어 | JA-Soprano-1 / Breathy / ただいま / Control_Group | 32.638초 | 46자 |

첫 추론 전에 manifest·채점 정책·평가 코드의 해시를 별도 고정했다. 실행 시 고정값을 검증했고 결과를 보고 정답을 고치지 않았다. 공개 주석에서 `<SP>`·`<AP>` 등 비가사 표지만 제외했다. 모든 모델에는 같은 음원 해시, 중립 파일명, 언어만 전달했다. 가사·제목·교정 프롬프트는 보내지 않았다. 모델의 학습 자료 중복은 알 수 없으므로 **이 로컬 평가에 처음 사용한 자료**라고만 표시하며 독립 학습 holdout을 주장하지 않는다.

## 정확도

오류율은 낮을수록 좋다. 기존 제품 평가 함수의 NFKC/casefold 및 문자 범주 L/N/M 기준으로 전체 출력의 편집 거리를 계산했다. 누락·중복을 포함하며 원래 출력에서 불리한 부분을 제거하지 않았다. 한국어의 주석은 음절 단위여서 부정확한 띄어쓰기 기반 WER을 만들지 않고 CER을 사용했다.

| 경로 | 한국어 CER · 54자 | 영어 WER · 47단어 | 일본어 엄격 CER · 46자 |
|---|---:|---:|---:|
| 현재 Qwen 제품 경로 | 57.41% · 31개 | 4.26% · 2개 | 30.43% · 14개 |
| xAI grok-voice-transcribe-2.0 | 29.63% · 16개 | 4.26% · 2개 | 2.17% · 1개 |
| OpenAI gpt-transcribe | 29.63% · 16개 | 4.26% · 2개 | 6.52% · 3개 |
| ElevenLabs Scribe v2 | 11.11% · 6개 | 6.38% · 3개 | 6.52% · 3개 |

일본어 보조 진단은 **추론 전에 고정한** pykakasi 2.3.0의 전체 문장 히라가나 변환을 정답·출력에 동일하게 적용했다. Qwen 15.09%(8/53), xAI 0%(0/53), OpenAI·ElevenLabs 3.77%(2/53)다. 특정 출력에 맞춘 치환은 없었다. 사전의 한자 읽기 선택은 잘못될 수 있어 원어민 청취 검수나 주 점수를 대체하지 않는다. 변환 후 0%도 전체 노래 인식 성능 100%를 의미하지 않는다.

## 처리 시간과 비용

각 경로 1회이며 요청 시작부터 응답 완료까지 초 단위다. 원격 API는 네트워크와 공급자 처리를 포함한다. 공급자 VRAM/RAM은 관측하지 않았다.

| 경로 | 한국어 | 영어 | 일본어 |
|---|---:|---:|---:|
| Qwen Worker | 17.683 | 16.410 | 14.299 |
| xAI | 1.133 | 0.704 | 0.906 |
| OpenAI | 2.382 | 1.432 | 2.445 |
| ElevenLabs | 1.832 | 1.876 | 1.700 |

Qwen 모델 처리 시간은 각각 13.319·12.663·10.949초다. 사용자 PC의 프로세스 메모리 및 CUDA 메모리 표본은 집계 JSON에 보관하며 GPU 사용량은 다른 프로그램을 포함하는 장치 전체 관측과 구분한다.

공급자당 96.3226875초다. 앞선 비교와 같은 표시 단가 xAI $0.10/시간, OpenAI $0.27/시간, ElevenLabs $0.22/시간을 사용한 기본 비용 추정은 이번 추가 9회에 약 **$0.015786**이다. 실제 계정 청구·세금·최소 과금·계약 요금은 확인하지 않았다. 요청 원장에 실행 전 비용을 예약했고 최대 9회/추정 $0.10 제한을 적용했다. 키는 기존 사용자별 DPAPI 저장소에서 읽고 코드·문서·Git에 저장하지 않았다. 요청된 비교를 위해 음원이 세 공급자에게 실제 전송됐다.

## 해석과 다음 검증

이번 한국어와 일본어에서 유료 경로의 개선 신호를 확인했다. 단, 언어당 한 곡·한 가수·한 번이며 무반주 분할 자료다. [공식 README](https://github.com/AaronZ345/GTSinger)는 한국어·일본어 주석 추가 정제를 미완료 항목으로 표시한다. 해당 주석의 축약·음절·표기와 실제 발음이 다를 수 있고 독립 원어민 청취 검수는 하지 않았다. 따라서 수치는 공개 고정 주석 대비 오류이며 실제 모든 발음 오류의 절대 정답으로 해석하지 않는다.

Qwen의 한국어·일본어 출력에는 제품의 구간 결합 불확실 경고와 끝부분 중복이 있었다. 중복을 포함해 채점했다. 한국어에는 언어가 섞인 오인식도 있었다. 이 비교는 제품의 분할·병합 경로와 공급자의 전체 입력 경로를 비교한 실사용 결과이며 Qwen 모델 가중치만의 성능 비교가 아니다. 실제 마이크 전에는 구간 경계와 병합 문제가 정확도에 미치는 영향을 별도 검증할 필요가 있다.

앞선 사용자 녹음에서 한국어 Qwen·ElevenLabs는 동률이고 일본어 표기 보조 진단에서도 Qwen·OpenAI·ElevenLabs가 동률이었다. 이번 개선만으로 모든 노래에 공통으로 우수한 공급자를 정하지 않는다. 우선 기본 Qwen을 유지하며 **한국어 ElevenLabs·일본어 xAI를 수동 선택 후보**로 둔다. 다음은 반주가 포함된 실제 마이크 녹음과 정확한 구간 가사를 확정한 비교다. 개선이 유지될 때 공급자 선택·외부 음원 전송 안내·비용 제한을 제품에 연결한다. 이번 작업에서는 자동 유료 호출이나 맞춤 학습을 제품에 추가하지 않았다.
