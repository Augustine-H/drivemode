# 가창 받아쓰기 추가 실측 — 2026-10-06

제품 버전 1.28.2. 유료 API 호출·음원 외부 전송·맞춤 학습은 실행하지 않았다. 실제 실행 상태와 수치를 다음에 기록한다.


기존 Qwen 기본 경로를 유지한다. 새 후보에서 일부 국소 개선은 있었으나 언어별 기본 모델을 교체할 만큼 일관된 독립 정확도 향상은 확인하지 못했다. 제품 코드·버전·NAS 배포는 변경하지 않았다.

- 베트남어 가창 Whisper: WER 97.26% → 100%, 86.67% → 86.67%. 보조 CER은 84.64% → 82.40%, 68.81% → 66.43%로 소폭 줄었지만 받아쓰기 품질이 충분하지 않다. 두 전체 파일의 추론은 2.598초·3.477초로 빨라졌으나 이를 정확도 개선으로 표시하지 않는다.
- 태국어 Distill Whisper: CER 84.72% → 85.65%, 115.38% → 669.23%. 기본 모델 교체를 권하지 않는다.
- 중국어 VocalParse: CER 11.90% → 38.10%, 79.17% → 2120.83%. 두 번째 파일은 두 구간 모두 512토큰 상한까지 반복 출력했다. 보조 AST 점수도 33.33%·100%로 기존 모델을 앞서지 못했다.
- ACE-Step NF4 중국어 추가 독창: 총 60자 기준 오류 6개 → 4개, 합산 CER 10% → 6.67%. 파일별로 0%/18.18%/10.53% → 0%/36.36%/0%로 개선과 악화가 섞였으며 자료가 매우 작다. 다른 기존 전체 파일에서는 크게 나빴으므로 중국어 기본 경로에 적용하지 않는다.
- BF16: 계획한 6개 중 5개 전체 파일을 완료했고 모두 기존 Qwen보다 나빴다. 사용자 요청으로 마지막 베트남어 파일을 중단했다. 미완료 파일의 점수와 완료 시간을 만들지 않았다.

## 비교 조건과 해석 범위

- RTX 4070 Ti 12 GB, 실제 CUDA 추론. 16 kHz 단일 채널, 30초 구간과 3초 겹침. 정답·곡명은 추론 입력에 사용하지 않았다.
- BF16 ACE-Step은 CPU/GPU에 분산 배치했다. 사용자 요청으로 마지막 베트남어 파일을 중단했고 계획한 6개 중 5개 전체 파일만 완료했다. 미완료 파일은 점수에서 제외한다. NF4는 GPU 배치이므로 순수 정밀도 차이만의 실험이 아니다. 반복 및 무관한 출력도 오류로 계산하며 토큰 상한 도달을 기록한다.
- 장치 GPU 사용량은 다른 앱을 포함한다. Torch 최대 할당량과 구분한다. RAM은 추론 프로세스의 샘플링된 working set이며 시스템 전체 RAM이 아니다.
- VocalParse는 공식 원본 core 클래스를 격리된 Transformers 4.57.6 환경에서 사용했다. 제품 Qwen의 HF 형식 5.18.0과 구현이 달라 순수 fine-tuning 효과만 분리하지 못한다. 전체 공식 batch API의 Windows 검증으로 확대하지 않는다.
- VocalParse는 가사 본문을 우선 사용하고 본문이 없는 유효한 AST 형식에서는 공식 AST 파서로 가사를 추출한다. AST 보조 점수는 진단용이며 정답에 따라 유리한 출력을 선택하지 않는다. 명시적인 반복 가사는 유지하고 melisma 연결 및 AP/SP 쉼 기호만 공식 정의에 따라 처리한다.
- 중국어 추가 세 음원은 같은 가수의 짧은 독창이며 상업 믹스·실제 마이크를 대표하지 않는다. VocalParse 공개 학습 주석에 정확한 경로가 있어 해당 후보의 독립 평가에서 제외했다. 다른 후보도 원어민의 별도 청취 검수까지 완료했다고 주장하지 않는다.
- THE TOYS의 La La Loy와 Bích Phương의 Bùa Yêu는 공식 30초 미리듣기이며 정확한 구간 정답이 검수되지 않았다. 사용자의 태국어 가사는 더 긴 구간이라고 확인돼 미리듣기 점수에서 제외했다. 처리 가능 여부와 시간은 측정하지만 정확도 향상은 미확정이다.

## 적용 판단

다음 비교는 실제 마이크·상업 믹스의 검수된 짧은 구간을 확보한 뒤 xAI REST STT, ElevenLabs Scribe v2, OpenAI gpt-transcribe의 제한된 유료 A/B를 우선 검토한다. 표시 단가상 공급자별 6분, 세 후보 합계 약 $0.059이며 실제 호출·과금은 하지 않았다. 외부 음원 전송과 예산은 별도 승인 범위다. 작은 보컬 맞춤 학습은 라이선스·원어민 정답·곡과 가수가 분리된 독립 시험 자료를 확보한 뒤 Whisper decoder LoRA부터 검토한다.

베트남어 첫 시험은 모델 로딩 진단의 Python set을 JSON으로 저장하지 못해 `TypeError: Object of type set is not JSON serializable`로 실패했다. 측정 기록 코드만 수정해 동일 모델·입력·디코딩으로 재실행했고 완료했다. 첫 오류와 Worker 복구 기록을 JSON에 보존했다. 다른 모델로 우회한 시험이 아니다.

로딩은 통제된 cold-cache 실험이 아니다. 특히 베트남어 재실행은 첫 로딩 이후의 warm-cache 영향이 있어 0.983초를 항상 보장되는 로딩 속도로 해석하지 않는다. 새로 시험한 VietLyrics·VocalParse·Thai Distill 모델의 체크포인트 누락·불일치·예상 밖 키는 0이었다. ACE-Step은 필요한 Thinker 가중치 누락·불일치가 0이며, 텍스트 전용 경로에서 쓰지 않는 Talker 293개와 Token2Wav 809개 키를 구분해 기록했다. Whisper는 언어/받아쓰기 decoder prefix를 실제 반환 토큰으로 확인했다. Worker 복구 코드는 모든 완료 시험과 중단 시험에서 0이다.

최종 운영 확인: Worker 인증 health 정상, activeJobId 없음, QUEUED 없음. NAS bridge `IDLE`·`workerReady=true`. 기존 개발/빌드 앱도 응답 중이며 제품 소스 변경이 없어 UI 빌드 검증을 반복하지 않았다.
