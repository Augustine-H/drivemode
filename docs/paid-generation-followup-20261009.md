# 유료 음악 생성 후속 테스트 — 2026-10-09

ElevenLabs Music v2.5를 기존 Windows Worker API로 호출했다. 60초·120초 연주곡과 영어·일본어 30초 보컬을 각각 한 번 요청했다. 한국어는 기존 30초 결과를 비교 기준으로 사용했다. 새 보컬은 직접 작성한 가사이며 특정 가수의 목소리를 지정하지 않았다.

성공한 WAV·MP3의 모든 프레임 디코딩, 비무음·유한 값·스테레오와 Worker 저장 메타데이터의 SHA-256 일치를 확인했다. WAV는 공급자 MP3를 디코딩한 파일이며 무손실 생성 원본이 아니다. 이번에는 NAS 업로드나 브라우저 재생을 새로 검사하지 않았다.

120초 요청은 HTTP 200 이후 `PAID_GENERATION_DURATION_MISMATCH`로 실패했다. 기존 구현은 ±0.25초보다 큰 길이 차이를 거절하며 실패 시 임시 응답을 삭제한다. 실제 반환 길이가 기록되지 않아 차이의 크기와 공급자 측 원인은 확인할 수 없다. 이를 숨기거나 길이 조건을 완화하지 않았고, 재호출하지 않았다. 실패 요청도 과금됐을 수 있다.

보컬 점수는 가사를 추론에 제공하지 않은 무료 로컬 Qwen 받아쓰기 결과와 정답의 문자 오류율(CER)이다. 영어 WER와 일본어 읽기 CER도 JSON에 기록했다. 기존 한국어 CER은 7.46%다. 언어마다 다른 가사·각 1회 표본이며 받아쓰기 오류도 포함되므로 생성 보컬의 발음·청감 품질 순위로 해석할 수 없다. 사람의 청취 평가는 수행하지 않았다.

공식 표시 단가 $0.15/분 기준 네 요청 합계 예상 $0.60(실패한 120초 포함). 실제 청구액은 미확인이다. 키는 기존 DPAPI 인증으로 사용했고 소스·로그·문서에 저장하지 않았다. 자동 재시도와 추가 유료 받아쓰기는 수행하지 않았다. [공식 가격](https://elevenlabs.io/pricing/api).
