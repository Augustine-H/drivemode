추가 API 호출 없이 보존한 실제 HTTP 응답을 HTTP mock으로 공급해 수정된 `generate()` 경로를 검증했다. 결과 WAV와 320 kbps MP3는 모두 120.032653초이고 비무음·유한 값·스테레오·전체 디코딩을 통과했다. 이 오프라인 검증은 새로운 공급자 생성이나 NAS 저장 검증이 아니다. 원래 실패한 Worker 작업 상태도 변경하지 않았다.
